# 경제적 자유 계산기 · 똑재TV

지금 자산·수입·생활비·국민연금을 넣으면 **일을 그만둬도 계획 나이까지 돈이 버티는 가장 빠른 나이(경제적 자유 나이)**와 생애 자산 흐름을 보여 주는 계산기.

- 사이트: https://ttokjaetv.github.io/freedom/
- 계산: 1년 단위, 모자란 돈은 연초 인출, 남는 돈은 매달 말 적립(월 수익률 = (1+연)^(1/12) − 1), 연말 투자 비중 재조정
- 수익률: 노후 자금 고갈 시뮬레이터와 같은 종목 프리셋 모듈(`src/pf-module.js`) + 보수적 보정
- 위기 시나리오: 은퇴 직후 폭락(첫 2년 연 −20%) · 주기적 불황 · 둠스데이 · 안전자산 전환
- 세금·건보료는 계산하지 않음(세전). 자세한 세금은 retire-drawdown으로 연결

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html` 생성. 엔진 검증은 `cd src && node test.js`.
`src/pf-module.js`·`src/pf.css`는 retire-drawdown에서 복사한 것이므로 그쪽 프리셋을 바꾸면 함께 바꾼다.
